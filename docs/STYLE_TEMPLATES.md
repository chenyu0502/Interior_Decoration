# 風格模板

本文件保存使用者定義的五種室內設計風格。程式中的對應資料位於 `js/data/styles.js`，其中 `features`（特色）、`colors`（色彩與材質）、`suits`（適用空間）三個欄位與本文件原文一致。

## 1. 現代風（Modern）

- 特色：俐落線條、重視機能配置與材質層次。
- 色彩與材質：中性色（如黑白灰、米色）、木質、石材與金屬。
- 適用空間：各坪數皆宜，特別適合追求時尚感與高效收納的家庭。

## 2. 北歐風（Scandinavian）

- 特色：明亮、溫暖，重視自然採光與生活感。
- 色彩與材質：淺色基底、木質家具、布料織品與局部跳色。
- 適用空間：中小坪數或採光需要被引進的空間。

## 3. 日系無印風（Japanese Muji）

- 特色：平靜配色、生活秩序與簡潔家具，強調空間流動。
- 色彩與材質：木色、米白與自然織品。
- 適用空間：小坪數、希望營造無壓與療癒氛圍的住宅。

## 4. 侘寂風（Wabi-Sabi）

- 特色：大量留白、自然紋理與不過度修飾的原始美感。
- 色彩與材質：米灰、低彩度大地色、特殊塗料（如微水泥）。
- 適用空間：追求沉靜、慢步調氛圍的空間。

## 5. 輕奢風（Modern Luxury）

- 特色：以簡潔底色搭配少量精緻細節，形成視覺焦點。
- 色彩與材質：柔和底色、石紋、金屬線條與精緻織品。
- 適用空間：中大型坪數或想局部營造質感的高級感住宅。

## 新增或修改風格

1. 開啟 `js/data/styles.js`。
2. 複製任一風格物件，修改 `id`、`name` 與說明文字。
3. 調整 `materials`（地坪、牆面、主題牆材質 id，見 `js/data/materials.js`）、`palette`（家具配色與家具腳造型）、`prefs`（偏好家具）、`tips`（各房型建議）。
4. 重新整理網頁，新風格會自動出現在「AI 風格」分頁。
