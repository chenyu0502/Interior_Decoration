# Interior Studio 室內設計工作室

免費開源的網頁室內設計工具，功能方向參考 Sweet Home 3D 與 Coohom。在 2D 平面圖上畫牆、拉房間、拖放家具與門窗，右側即時生成 3D 透視圖；選擇風格模板後，AI 會依平面圖自動配置家具、材質與配色，並產出設計建議書。

整個專案是純前端靜態網頁，不需要後端、不需要建置流程，所有第三方函式庫（Three.js、Anthropic SDK）已放在 `vendor/`，可離線使用。

## 功能

### 1. 2D 平面圖編輯

- 畫牆：連續點擊畫牆，自動吸附端點、牆線、15° 角度與 5 cm 格點。
- 房間：拖曳建立矩形房間（自動產生四面牆），或用多邊形工具畫不規則地板。
- 自動偵測房間：依封閉牆體自動找出房間；新增隔間牆後可自動分割房間。
- 調整：拖曳牆體或端點（相連的牆會一起移動）、拖曳房間頂點、從中間分割牆。
- 量尺標註、面積與坪數即時顯示。
- 底圖描圖：匯入平面圖圖片，點兩點輸入實際長度即可校正比例，再沿著底圖畫牆。

### 2. 家具與門窗（拖拉式操作）

- 50 多件家具：沙發、茶几、電視櫃、書櫃、餐桌椅、床、衣櫃、書桌、流理台、冰箱、中島、馬桶、浴缸、淋浴間、燈具、植栽、掛畫、窗簾等。
- 10 種門窗：單開門、雙開門、推拉門、玄關大門、門洞、一般窗、橫拉長窗、落地窗、浴室高窗、景觀窗。
- 從左側目錄拖曳到 2D 或 3D 畫面放置；門窗自動吸附到最近的牆。
- 家具靠近牆面自動貼齊轉向（按住 Alt 取消）；藍色圓點旋轉、方點縮放；可在右側調整尺寸、離地高度與顏色。
- 3D 畫面中可直接拖曳家具。

### 3. 3D 透視圖

- 由平面圖即時生成牆體、門窗開口、地板與家具。
- 環繞檢視、俯視、矮牆剖切、顯示天花板、日間 / 夜間燈光。
- 第一人稱漫遊：W A S D 移動、拖曳滑鼠環顧，2D 平面圖同步顯示所在位置與視角。
- 匯出 2D 平面圖與 3D 透視圖 PNG。

### 4. 材質

- 34 種程序化材質（不需外部圖片）：木地板、人字拼、石英磚、大理石、洞石、磨石子、微水泥、清水模、榻榻米、乳膠漆、礦物塗料、木格柵、文化磚、壁紙、地鐵磚等。
- 牆的兩面可分別設定材質；可整個房間一次套用；可直接把材質拖曳到 3D 牆面或地板。

### 5. 風格模板與 AI 自動設計

內建五種風格模板（現代風、北歐風、日系無印風、侘寂風、輕奢風），完整內容見 [docs/STYLE_TEMPLATES.md](docs/STYLE_TEMPLATES.md)。

AI 自動設計流程：

1. 分析房間：依名稱與面積判斷房型（客廳、主臥、臥室、書房、廚房、浴室、玄關、走道、陽台、更衣室），可手動修正。
2. 分析動線：找出每面牆上的門、窗、開門範圍與開放邊，標記需要淨空的區域。
3. 配置家具：依房型套用配置規則，例如沙發與電視牆相對、床頭靠實牆避開門窗、餐桌置中保留走道、廚具依冰箱、水槽、爐具動線排列、客餐廳過大時自動切分客廳區與餐廳區。
4. 套用風格：地坪、牆面、主題牆（電視牆、沙發背牆、床頭牆）、家具造型與配色。
5. 產出設計建議書：各空間坪數、材質、配置說明與風格建議。

三種套用方式：重新配置、保留現有家具只補齊、只換材質配色。也可以在房間屬性中「只設計這個房間」。

AI 引擎是規則式演算法，在瀏覽器本機執行，不需網路與帳號。

選用功能：在設計建議書中輸入自己的 Anthropic API Key，可由 Claude 撰寫更完整的設計提案（色彩計畫、逐室建議、預算分配）。金鑰只存在您的瀏覽器（localStorage），由瀏覽器直接連線 Anthropic API。

## 使用方式

由於網頁使用 ES Module，需透過本機伺服器開啟，不能直接雙擊 `index.html`。

### Windows

雙擊 `start.bat`，會自動用 Python 或 Node.js 啟動伺服器並開啟瀏覽器（http://localhost:8080）。

### 手動啟動

任選一種：

```bash
# Python
py -m http.server 8080

# Node.js
npx http-server -p 8080 -c-1
```

再以瀏覽器開啟 http://localhost:8080 。

### 部署到 GitHub Pages

1. 到 GitHub 專案的 Settings → Pages。
2. Source 選擇 `Deploy from a branch`，分支選擇要發布的分支、資料夾選 `/ (root)`。
3. 儲存後即可透過 `https://<帳號>.github.io/<專案名稱>/` 使用。

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| V / W / R / P / D / H | 選取 / 畫牆 / 房間 / 多邊形 / 量尺 / 平移 |
| R（選取家具時） | 旋轉 90° |
| 方向鍵（Shift 加速） | 微調位置 1 cm（10 cm） |
| Delete | 刪除 |
| Ctrl + D | 複製家具 |
| Ctrl + Z / Ctrl + Y | 復原 / 重做 |
| Ctrl + S | 儲存專案檔 |
| Esc | 取消目前工具 |
| 空白鍵 + 拖曳、滑鼠中鍵 | 平移畫面 |

## 資料儲存

- 專案會自動存到瀏覽器 localStorage，重新開啟網頁會回到上次的狀態。
- 「檔案 → 儲存專案檔」匯出 `.json`，可在其他電腦「開啟專案檔」繼續編輯。

## 專案結構

```
index.html              頁面版面
css/app.css             樣式
js/main.js              介面控制、目錄、屬性面板、檔案、快捷鍵
js/core/state.js        專案資料、選取、復原 / 重做、自動存檔
js/core/geometry.js     幾何計算、房間偵測、最大內接矩形
js/core/model.js        牆角接合、門窗位置、牆與房間關係
js/editor/plan2d.js     2D 平面圖編輯器
js/editor/view3d.js     3D 檢視（Three.js）
js/data/catalog.js      家具與門窗（2D 符號與 3D 程序化模型）
js/data/materials.js    材質庫與程序化貼圖
js/data/styles.js       風格模板
js/data/samples.js      範例平面圖
js/ai/designer.js       AI 自動設計引擎
js/ai/claude.js         選用的 Claude API 設計提案
vendor/                 Three.js r169、Anthropic TypeScript SDK（瀏覽器打包版）
docs/STYLE_TEMPLATES.md 風格模板說明
```
