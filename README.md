# Interior Studio 室內設計工作室

免費開源的網頁室內設計工具，功能方向參考 Sweet Home 3D 與 Coohom。在 2D 平面圖上畫牆、拉房間、拖放家具與門窗，右側即時生成 3D 透視圖；選擇風格模板後，AI 會依平面圖自動配置家具、材質與配色，並產出設計建議書。

整個專案是純前端靜態網頁，不需要後端、不需要建置流程，所有第三方函式庫（Three.js、Anthropic SDK）已放在 `vendor/`，可離線使用。

## 功能

### 1. 2D 平面圖編輯

- 畫牆：連續點擊畫牆，自動吸附端點、牆線、15° 角度與 5 cm 格點。
- 房間：拖曳建立矩形房間（自動產生四面牆），或用多邊形工具畫不規則地板。
- 自動偵測房間：依封閉牆體自動找出房間；新增隔間牆後可自動分割房間。
- 調整：拖曳牆體或端點（相連的牆會一起移動）、拖曳房間頂點、從中間分割牆。
- 量尺標註、面積與坪數即時顯示。
- 比例尺與坪數調整：畫面左上角顯示比例尺；未選取物件時，在右側專案面板輸入目標坪數或縮放百分比，整張平面圖等比縮放（牆厚、門窗與家具尺寸不變）。也可以選取一面牆、一段量尺或一個房間，按「以此…校正整體比例」輸入實際長度或坪數。
- 從圖片自動建立平面圖：「檔案 → 從圖片自動建立平面圖」選擇 PNG / JPG，系統自動辨識牆體、門、窗與門洞，依門寬推估比例尺，接合轉角、偵測房間並推斷房型，結果不保留底圖（詳見下方說明）。
- 底圖描圖：匯入平面圖圖片，點兩點輸入實際長度即可校正比例，再沿著底圖畫牆。

### 2. 家具與門窗（拖拉式操作）

- 50 多件家具：沙發、貴妃椅、茶几、電視櫃、書櫃、四分之一圓角落層櫃、餐桌椅、床、衣櫃、書桌、流理台、冰箱、中島、馬桶、浴缸、淋浴間、燈具、植栽、掛畫、窗簾等。
- 角落家具（例如角落層櫃）靠近牆角時，背面與側面會同時貼齊兩面牆，翻轉可切換左右牆角。
- 可調參數的家具：格子層櫃可設定欄數與層數（N × N 格）、背板與擺飾；中島可設定電器櫃寬、電器層數與是否顯示電器。選取後在右側屬性面板修改。
- 10 種門窗：單開門、雙開門、推拉門、玄關大門、門洞、一般窗、橫拉長窗、落地窗、浴室高窗、景觀窗。
- 3 種戶外柵欄（在「門窗」分頁）：木柵欄、金屬欄杆、橫格柵圍籬，可放在陽台、庭院；拉長時立柱與板材自動增加，AI 重新配置時會保留。
- 從左側目錄拖曳到 2D 或 3D 畫面放置；門窗自動吸附到最近的牆。
- 目錄縮圖為實景照片風格：家具擺在房間一角，以光線追蹤計算窗邊日光、柔和陰影與反射；門窗嵌在整面牆上，看得到窗外景色。地板、牆面與家具配色依目前風格變化，完成的縮圖存在瀏覽器，下次開啟直接使用。
- 門窗外觀：選取門後可設定門片材質（木紋、霧面烤漆、亮面烤漆、金屬、玻璃）與顏色；門與窗都可設定框材質與顏色，未自訂時跟隨風格配色。
- 家具靠近牆面自動貼齊轉向（按住 Alt 取消）；藍色圓點旋轉、方點縮放；可在右側調整尺寸、離地高度與顏色。
- 左右翻轉：例如流理台水槽與爐具互換、L 型沙發貴妃椅換邊（屬性面板「⇆ 翻轉」或 M 鍵）。
- 3D 畫面中可直接拖曳家具。

### 3. 3D 透視圖

- 由平面圖即時生成牆體、門窗開口、地板與家具。
- 環繞檢視、俯視、矮牆剖切、顯示天花板、日間 / 夜間燈光。
- 即時畫面使用寫實材質（布料絨面、木作清漆、石材反光、凹凸紋理）與天空背景。
- 實景模式（3D 工具列「◐ 實景」，預設開啟）：停止操作片刻後，3D 畫面會直接以光線追蹤逐步算成照片般的效果（窗外日光、光線反彈、柔和陰影與反射），左上角顯示進度；漫遊時站定不動就像身歷其境。移動視角或修改設計時立即切回即時畫面。裝置無法執行時會自動降低解析度重試，仍不行則在畫面顯示原因與顯示卡型號。
- 第一人稱漫遊：W A S D 移動、拖曳滑鼠環顧，2D 平面圖同步顯示所在位置與視角。
- 漫遊時點擊（滑鼠點選、手機點觸）即可開關：門依平面圖的開門方向轉開、推拉門與推拉窗滑開；衣櫃（內有摺好的衣物與吊掛的衣服）、鞋櫃（每層擺著鞋子）、各式櫃子、流理台的門片與抽屜、浴櫃、書桌與化妝台抽屜、淋浴間玻璃門、馬桶蓋、冰箱（內有飲料、水果與冷凍食品）、洗衣機、烤箱、微波爐也都能開關，每扇門、每個抽屜各自動作。
- 手機漫遊：左下虛擬搖桿移動、拖曳畫面環顧；按右下「◎ 陀螺儀」後轉動手機即可環顧四周（iPhone 會詢問「動作與方向」權限，請按允許）。360° 環景檢視與下載的檢視網頁也支援陀螺儀。
- 匯出 2D 平面圖與 3D 透視圖 PNG。
- 寫實渲染：以光線追蹤（path tracing）產生效果圖，計算光線在室內多次反彈、柔和陰影、磁磚與大理石反射、玻璃折射、材質凹凸，並自動曝光與降噪（詳見下方說明）。

### 4. 材質

- 34 種程序化材質（不需外部圖片）：木地板、人字拼、石英磚、大理石、洞石、磨石子、微水泥、清水模、榻榻米、乳膠漆、礦物塗料、木格柵、文化磚、壁紙、地鐵磚等。
- 材質縮圖以放在桌面上的圓角方塊呈現紋理、凹凸與反光（光線追蹤拍攝）。
- 牆的兩面可分別設定材質；可整個房間一次套用；可直接把材質拖曳到 3D 牆面或地板。

### 5. 風格模板與 AI 自動設計

內建五種風格模板（現代風、北歐風、日系無印風、侘寂風、輕奢風），完整內容見 [docs/STYLE_TEMPLATES.md](docs/STYLE_TEMPLATES.md)。

AI 自動設計流程：

1. 分析房間：依名稱與面積判斷房型（客廳、主臥、臥室、書房、廚房、浴室、玄關、走道、陽台、更衣室），可手動修正。
2. 分析動線：找出每面牆上的門、窗、開門範圍與開放邊，標記需要淨空的區域。
3. 配置家具：依房型套用配置規則，例如沙發與電視牆相對、床頭靠實牆避開門窗、餐桌置中保留走道、廚具依冰箱、水槽、爐具動線排列、客餐廳過大時自動切分客廳區與餐廳區。
4. 套用風格：地坪、牆面、主題牆（電視牆、沙發背牆、床頭牆）、家具造型與配色。
5. 產出設計建議書：各空間坪數、材質、配置說明與風格建議。

三種套用方式：重新配置、保留現有家具只補齊、只換材質配色。也可以在房間屬性中「只設計這個房間」。

AI 引擎是規則式演算法，在瀏覽器本機執行，不需網路與帳號。

選用功能：在設計建議書中輸入自己的 Anthropic API Key，可由 Claude 撰寫更完整的設計提案（色彩計畫、逐室建議、預算分配）。金鑰只存在您的瀏覽器（localStorage），由瀏覽器直接連線 Anthropic API。

### 一句話改設計

按上方「✎ 一句話」（手機為底部「一句話」，鍵盤按 `/`），用打字或語音（支援的瀏覽器會顯示「語音」按鈕）說出想要的修改，Claude 會直接修改設計，並列出每一步：

- 「沙發移到窗邊」「電視櫃靠著沙發對面的牆」：家具背靠指定的牆、對齊窗戶，正面朝向房內。
- 「主臥加一張書桌」「把餐桌刪掉」「沙發換成深藍色、寬 240」：新增、刪除、調整尺寸與顏色。
- 「客廳地板換成胡桃木」「主臥牆面刷成霧霾藍」：更換地板與牆面材質。
- 「整間改成日式無印風」「晚上開燈看看」：套用風格、切換日夜燈光。

放置家具時會自動檢查是否超出房間、和其他家具重疊或擋住門，有問題會自行調整。每句指令的修改合併成一個步驟，可按「復原這次修改」一次退回；可以接著說「再往左一點」繼續調整。需要自己的 Anthropic API Key（只儲存在瀏覽器，直接連線 Anthropic API）。

## 日照模擬（西曬檢查）

1. 按 3D 畫面右上角「◔ 日照」（手機請先切到 3D 或分割畫面）。
2. 選擇城市，拖曳「座向」設定平面圖上哪一邊是正北（2D 平面圖右上角的指北針會跟著轉）。
3. 選日期（可一鍵切換今天、春分、夏至、秋分、冬至），拖曳時間軸或按「播放」看太陽從早到晚的變化。

- 面板停靠在畫面底部，2D 與 3D 畫面會自動縮短讓出空間，不會被蓋住；按「統計」展開各房間的日照表，按「收合」只留時間軸。
- 3D 畫面依真實太陽位置投下陽光與陰影，陽光只會從窗戶照進室內；漫遊時站定，實景模式會算出該時刻的光影照片。
- 2D 平面圖以黃色標出此刻陽光照到的地板。
- 「統計」列出每個房間的直射日照時數、時段與西曬時段（下午 2 點後太陽在西南到西北方）。
- 只計算外牆上的窗戶與玻璃門，不含鄰棟、陽台、遮雨棚等室外遮蔽。

## 導覽影片

1. 按 3D 畫面右上角「▶ 導覽影片」（或「檔案 → 產生導覽影片」）。
2. 選擇畫面比例（橫式 16:9、直式 9:16、方形 1:1）、畫質（720p / 1080p）與節奏，面板會列出走訪順序與預估長度。
3. 編輯走訪順序：用 ↑ ↓ 調整順序、取消勾選略過不拍的空間，選擇房間後按「＋ 新增一站」可增加站點（同一個房間可以有多站，例如客廳、餐廳各一站，並可自訂字幕名稱）。每一站可以設定：
   - 視角：自動、朝向房內的某件家具或門窗（例如朝向流理台），或按「擷取 3D」使用目前 3D 畫面的位置與方向（先關閉視窗，在 3D 畫面或漫遊中轉到想要的角度再回來按）。
   - 轉向：鏡頭往左或往右轉；停留：多停 3 到 10 秒。
   - 特別注意的細節：例如「床頭主牆的掛畫、窗邊的貴妃椅」，提到房內的家具、門窗、地板或天花板會加拍特寫並以描述當字幕，其他文字顯示在房間字幕下方；沒填就照原設計運鏡。
   - 按「預覽」可在右側看到這一站開始、中段、結束三格畫面。每一站下方會顯示實際怎麼拍，按「重設」恢復自動排列。
4. 按「開始錄製」，完成後可在視窗內播放，按「下載影片」存成 MP4；手機上可按「分享」直接傳到 LINE 或其他 App。

- 從空拍開場，依門的連通順序穿過門口走進每個房間（經過時自動開門），每個房間從角落推近並橫移，最後拉回空拍收尾。
- 左下角顯示房間名稱與坪數，可在選項中關閉。影片使用目前的風格、材質、日夜與日照設定。
- 影片逐格製作成 30 fps：電腦較慢時只是製作時間較久，影片一樣流暢。製作時請保持分頁在前景。

## 分享連結與 QR code

1. 按「檔案 → 分享連結與 QR code」。
2. 「分享連結」不需要任何設定，按「複製」貼到 LINE 或 email 即可。設計資料壓縮後放在網址 # 之後，不經過任何伺服器；底圖不會一起分享。
3. 要給客戶掃描的 QR code，需要短網址：依視窗中的步驟到 GitHub 建立權杖（只需勾選 gist 權限），貼上並儲存（只存在這個瀏覽器），再按「產生短網址與 QR code」。設計會存成您 GitHub 帳號下不公開的 Gist，可按「下載 QR code 圖片」列印或放進簡報。

- 對方開啟分享的設計時為唯讀檢視：修改不會自動存檔，也不會覆蓋對方自己的專案；可按「存成我的專案」保留。手機開啟時直接顯示 3D 畫面。
- 分享的是當下的設計，之後修改需要重新分享。不公開的 Gist 不會出現在搜尋結果，但知道網址的人都能看；不需要時可到 GitHub 的 Gist 頁面刪除。

## 寫實渲染

1. 在 3D 畫面轉到想看的角度，或按「漫遊」走進房間、調整視線高度與方向。
2. 按 3D 畫面右上角「✦ 渲染」（或「檔案 → 寫實渲染（光線追蹤）」）。
3. 選擇：
   - 時段：白天、黃昏、夜晚（夜晚與黃昏依燈具位置點燈，沒有主燈的房間自動補一盞吸頂燈）。
   - 品質：草稿、標準、精細，品質越高解析度與取樣次數越多、越清晰，也越耗時。
   - 畫面比例、太陽方位、是否顯示天花板、是否開啟室內燈光。
   - 畫質：自動曝光、降噪、材質凹凸細節（建議都開啟）；色調：自然、電影感、鮮明。
4. 按「開始渲染」，畫面會逐步由顆粒狀變清晰；可隨時「停止」。完成後可拖曳「亮度」調整，再「下載圖片」。
   - 進度條與效果圖左上角顯示完成百分比，下方顯示已用時間與預估剩餘時間；準備階段顯示跑馬條。
   - 瀏覽器分頁標題也會顯示進度。渲染中請保持分頁在前景，切到其他分頁時瀏覽器會暫停渲染。

### 360° 環景圖

1. 在渲染視窗的「輸出」選擇「360° 環景圖」。
2. 「拍攝位置」選擇「目前漫遊位置」（需先進入漫遊）或任一房間中央，拍攝高度為視線高度 150 cm 左右，天花板會自動開啟。
3. 開始渲染，完成後畫面可直接拖曳環顧、滾輪或雙指縮放；按「平面圖片 / 360° 檢視」切換顯示方式。
4. 「下載圖片」得到 2:1 等距柱狀環景圖（草稿 2048 × 1024、標準 3072 × 1536、精細 4096 × 2048）；「下載 360° 檢視網頁」得到單一 HTML 檔，圖片已內嵌，傳給客戶用瀏覽器開啟即可環顧，不需網路與安裝。

注意事項：

- 渲染在瀏覽器內以顯示卡計算，速度取決於顯示卡效能；需要支援 WebGL2 的瀏覽器（Chrome、Edge、Firefox、Safari 新版）。
- 室內視角建議勾選「天花板」，光線才會在室內正確反彈；從上方俯瞰時請取消勾選。
- 第一次渲染需要載入引擎與準備著色器，會多等幾秒。
- 引擎可選「光線追蹤（寫實）」或「相容模式（快速）」。光線追蹤在部分顯示卡（例如記憶體較少的內建顯示卡）可能無法正常輸出，系統偵測到全黑或錯誤時會自動改用相容模式，並在下方顯示原因與顯示卡型號。

## VR 頭盔模式

1. 戴上支援 WebXR 的 VR 頭盔（例如 Meta Quest 2、3、Pro），用頭盔內建的瀏覽器開啟網站（需要 HTTPS，GitHub Pages 網址可直接使用）。
2. 在電腦或頭盔上先畫好平面圖、擺好家具；可先按「漫遊」走到想開始的位置。
3. 按 3D 畫面右上角「◈ VR」進入，以實際尺寸站在室內，天花板會自動顯示。
4. 操作方式：
   - 左搖桿：往面向的方向移動，會被牆擋住。
   - 右搖桿：左右推每次轉 30°。
   - 扳機：按住並指向地板會出現藍色圓環，放開即瞬間移動過去。
5. 按頭盔的系統按鈕或再按一次「◈ 離開 VR」結束。
6. 只有支援 VR 的瀏覽器會顯示「◈ VR」按鈕，一般電腦與手機不會出現。

## 手機版

- 2D 與 3D 畫面滿版顯示，底部有「家具、門窗、材質、AI 風格、屬性」五個按鈕，點選後面板由下方滑出，再點一次或按「✕」收起。
- 放置家具或門窗：點卡片後面板自動收起並顯示 2D 平面圖，再點平面圖要放的位置。
- 套用材質：先在平面圖點選房間或牆，再開「材質」點選材質。
- 修改尺寸、顏色等：選取物件後按「屬性」（有新選取時按鈕會出現藍點）。

## 從圖片自動建立平面圖

1. 點「檔案 → 從圖片自動建立平面圖（PNG / JPG）」，選擇格局圖。
2. 系統自動完成：
   - 辨識牆體：保留深色粗線，去除門弧線、尺寸線、文字與家具細線。
   - 辨識門窗：牆上的缺口依內容分類，有平行細線者在外牆為窗、在內牆為推拉門；旁邊有門弧線者為門（含開門方向）；其餘為門洞。
   - 推估比例尺：以偵測到的門寬中位數為 85 cm 換算；沒有門時以牆厚約 15 cm 換算。
   - 接合轉角、偵測房間，並依面積與門的連通關係推斷房型（客廳、主臥室、臥室、書房、廚房、浴室、走道）。
3. 跳出的視窗會顯示推估的外框尺寸；知道實際總寬度時輸入公分數即可校正，不確定直接按確定。之後也可以用專案面板的「目標坪數」或選取已知長度的牆重新校正。
4. 結果不含底圖。不滿意可按 Ctrl+Z 復原。

辨識限制：

- 只辨識水平與垂直的牆，斜牆、弧形牆需手動補畫。
- 牆需為深色實心或斜線填充的粗線；只用細線畫牆的圖面無法辨識，請改用「匯入平面圖底圖（手動描圖）」。
- 手機拍攝的紙本型錄可辨識外牆與大部分隔間，但家具陰影、深色家具可能產生多餘短牆，部分隔間或門可能遺漏；匯入後請檢查並用「畫牆」補上、刪除多餘的牆。拍攝時請盡量正對紙面、避免反光。
- 窗台高度、落地窗與一般窗無法從圖面判斷，預設為一般窗，可點選後在右側修改。
- 房型依面積推斷，主臥室與其他臥室可能對調，可在右側或「AI 風格」分頁修改。

## 使用方式

由於網頁使用 ES Module，需透過本機伺服器開啟，不能直接雙擊 `index.html`。

### Windows

雙擊 `start.bat`，會自動用 Python 或 Node.js 啟動伺服器並開啟瀏覽器（http://localhost:8080）。

### 手動啟動

任選一種：

```bash
# Python
py -m http.server 8080

# Node.js
npx http-server -p 8080 -c-1
```

再以瀏覽器開啟 http://localhost:8080 。

### 部署到 GitHub Pages

專案已內建自動部署 workflow（`.github/workflows/pages.yml`），每次合併到 `main` 都會自動發布。

1. 到 GitHub 專案的 Settings → Pages。
2. Source 選擇 `GitHub Actions`（只需設定一次）。
3. 到 Actions 分頁確認「部署 GitHub Pages」執行成功，即可透過 `https://<帳號>.github.io/<專案名稱>/` 使用。
4. 需要手動重新部署時，在 Actions 分頁選擇「部署 GitHub Pages」並按 `Run workflow`。

## 版本與更新

- 狀態列右下角顯示目前版本，點選可查看版本紀錄（完整紀錄見 [CHANGELOG.md](CHANGELOG.md)）。
- 網站開啟 3 秒後、之後每 5 分鐘、以及切回分頁時，會檢查伺服器上是否有新版本。有新版本時跳出確認視窗：
  - 立即更新：先自動存檔，重新下載程式後重新整理頁面，目前的設計會自動還原。
  - 稍後再說：本次瀏覽期間不再提醒，可隨時從「檔案 → 檢查更新」手動更新。

發布新版本的步驟（維護者）：

1. 修改 `js/version.js` 的 `VERSION`，並在 `CHANGELOG` 最前面新增一筆更新內容。
2. 同步更新 `CHANGELOG.md` 與 `package.json` 的版本號。
3. 合併到 `main` 後自動部署，使用中的網頁會在 5 分鐘內跳出更新提示。
4. 在合併後的提交建立對應的 Git 標籤（例如 `v1.3.0`）。
